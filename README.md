# 図面テレビ電話（デモ）

事務所と現場をつなぐ「図面テレビ電話」を、**1台の端末（PC・スマホ）だけで紹介するためのデモ**です。通信は一切せず、図面やカメラ映像はこの端末の中だけで扱います。

## 使い方

1. このページ（GitHub Pages の URL）を、スマホなら Safari / Chrome、PC なら Chrome / Edge で開きます。
2. 相手（現場1など）の「呼び出す」を押すと、数秒呼出音が鳴ったあと、同じ画面が相手側の着信画面（点滅・着信音）になります。
3. 「出る」を押すと、この端末のカメラ映像が相手の映像として映ります（初回はカメラの使用を「許可」）。
4. 図面（PDF・画像）を開く、ポインター、蛍光ペン、撮影、チャット（自動返信）、「出られない（折り返します）」を試せます。

部品：PDF.js 3.11.174（Apache License 2.0）

## 2台で本物の通話を見せる

インターネットにつながった2台の端末で、それぞれ次のページを開きます（Chrome / Edge / Safari）。

- 事務所役：`office.html`
- 現場役：`site.html`

両方に「待受中」と出たら、事務所役で「現場1」の「呼び出す」を押します。現場役で着信が鳴り、「出る」で通話になります。デモ専用の合言葉を使うので、本番の相手とはつながりません。

## 社外の方との打ち合わせ（本番用）：`meet/`

`meet/` は、社外の方（取引先・お客様）が招待リンクから入室するためのページです（デモではなく本番用）。

- 自社側が「招待リンクを作る」で作ったリンク（`…/meet/#j=…`）を開くと、入室の画面になります。名前を入れて「入室する」を押し、自社側が許可すると打ち合わせが始まります。
- リンクなしで `meet/` を開くと、設定ファイルなしで「招待リンクを作る」だけが使えます（Dropbox 版がない端末から打ち合わせを主催するとき用）。
- このページには社内用の合言葉や設定は含まれていません。部屋番号は推測できない乱数で、入室は自社側の許可が必要です。
